# Phase 5 — MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Serve a streamable-HTTP MCP server at `/mcp` with API-key auth and per-IP rate limiting, exposing the site's content as typed tools — profile, projects, experience, skills, posts, tags, the posts kill switch, SEO settings, and whole-content export/import — so an agent can read and edit everything the REST API can.

**Architecture:** A new `internal/mcp` package owns the `mcp-go` server and tool handlers. It depends only on `internal/db` plus two function fields (`Reload func() error`, `APIKey func() (string, error)`), so it never imports `internal/web`. `internal/web` mounts `mcp.Handler(deps)` at `/mcp` inside the existing chi router; `/mcp` is already CSRF-exempt. Tool handlers are plain methods on a `Backend` that tests call directly; the wire layer is thin.

**Tech Stack:** Go 1.25, `github.com/mark3labs/mcp-go` (`mcp`, `server`), `modernc.org/sqlite` (CGO-free), `net/http`.

**Spec:** `docs/superpowers/specs/2026-09-16-johansenfoo-agent-first-site-design.md` (MCP Tools; Auth & Security; Implementation Phases §5)

## Global Constraints

- `CGO_ENABLED=0` for build/test; module `github.com/mojoaar/johansenfoo`, Go 1.25.5.
- No comments in Go code unless essential.
- All SQL parameterized; timestamps RFC 3339 UTC.
- Typed schemas, agent-oriented descriptions, snake_case tool names; errors returned via `mcp.NewToolResultError`.
- Paired `enable_posts` / `disable_posts` tools — never a boolean flag argument.
- Every successful write calls the injected `Reload` (so the public site updates on the next request).
- Rate limit MCP at 100 requests/minute per IP (spec). Auth is `Authorization: Bearer <api-key>`.
- Migrations append-only; Phase 5 adds none.
- Docs are part of the definition of done.

## Scope

In scope: the MCP server, auth, rate limiting, and tools for profile, projects, experience, skills, posts, tags, `enable_posts`/`disable_posts`, `get_seo_settings`/`update_seo_settings`, `export_content`/`import_content`.

Out of scope (later phases, do not stub): theme tools (`list_themes` … `import_theme`, Phase 6) and stats tools (Phase 7).

## Review Focus

1. **Unauthenticated or wrong-key MCP access.** `/mcp` must return 401 without a matching Bearer key, and must not 500 when no key is configured.
2. **A tool write that forgets `Reload`**, leaving the public site stale.
3. **Tool errors crashing the request** instead of returning `mcp.NewToolResultError`.
4. **Rate limiting**: the 101st request in a window returns 429; the limiter does not leak unbounded memory.
5. **Argument handling**: missing required arguments and malformed ids produce a tool error, not a panic; optional arguments merge over existing values rather than blanking them.

### Task 1: MCP dependency, server core, auth and rate limiting

**Files:** create `internal/mcp/backend.go`, `internal/mcp/server.go`, `internal/mcp/auth.go`, `internal/mcp/server_test.go`; modify `go.mod`.

**Interfaces:**
- `mcp.Deps{ DB *sql.DB; Reload func() error; APIKey func() (string, error) }`
- `mcp.Backend` struct `{ DB *sql.DB; Reload func() error }` with helper `func (b Backend) reload() error`.
- `func jsonResult(v any, err error) (*mcp.CallToolResult, error)` → `NewToolResultText` of indented JSON, or `NewToolResultError`.
- `func NewServer(b Backend) *server.MCPServer` (name `"johansenfoo"`, version from a `Version` field).
- `func Handler(d Deps) http.Handler` → rate-limited, bearer-authenticated wrapper around `server.NewStreamableHTTPServer(NewServer(...))`.
- `func bearerAuthorized(r *http.Request, key string) bool` using `crypto/subtle`.

## Phase 5 Definition of Done

- `/mcp` serves streamable HTTP behind `Authorization: Bearer <api-key>`, 100 req/min/IP, 401 without a key.
- 28 tools registered with typed schemas and snake_case names; writes reload the content snapshot.
- Tool errors return `mcp.NewToolResultError`, never a panic or a 500.
- `/api/` and `/mcp` remain CSRF-exempt; no new migration; gates clean; docs updated.

## Out of scope

- Theme tools (Phase 6) and stats tools (Phase 7).
- MCP OAuth or per-tool scopes; a single API key is the whole auth model.
